# Android application network and execution surface

This source-level inventory covers audited commit `e0cc30951e24ec018423bb113acfe7849f9836d5` and its pinned Go AAR source tag `v1.15.1`, checked 2026-09-13. It excludes Android framework and transitive dependency internals. Kotlin paths below omit the common `app/src/main/java/dev/stunmesh/android/` prefix unless stated otherwise. Production Kotlin source and the merged debug/release manifests were reviewed separately; a source scan alone cannot prove that a compiled dependency has no hidden behavior.

| Source | Surface | Trust boundary |
| --- | --- | --- |
| `service/StunmeshVpnService.kt` | The exported VPN service requires Android's `BIND_VPN_SERVICE`; it provides the TUN fd and calls `VpnService.protect` for outer sockets. | Android's VPN permission/consent gates service use. The app does not call `startForeground` (A-15). Its default-network callback can miss a physical underlay change while the VPN remains the app's default (A-20, conditional). |
| `tunnel/TunnelManager.kt`, `app/src/gobackend/kotlin/dev/stunmesh/android/backend/GoBackend.kt` | Reflection loads the locally packaged Go binding class and passes configuration/callbacks into it. | There is no arbitrary class name or network-loaded code in these paths. A missing/failing Go binding falls back to a packet-dropping stub; even the real backend reports `UP` before peer handshake (A-04). |
| `config/TunnelYaml.kt`, `WgQuickConf.kt`, `MainActivity.kt` | User-selected YAML/WireGuard configuration files are read and parsed; export writes full plaintext credentials to a user-selected document. | User action is required. Size is unbounded (A-07), imported plugin type is not allowlisted (A-02), and malformed errors can reach manual log exports (A-14). |
| `config/ConfigRepository.kt` | App-private AES-GCM ciphertext file plus Android Keystore key. | An unreadable restored/corrupt file is silently treated as empty (A-05). The code does not attest hardware backing. |
| `ui/StatusScreen.kt`, `config/TunnelConfig.kt` | Manual diagnostic export includes redacted configuration and rolling logs. | Generic plugin credentials are not fully redacted (A-06), and earlier parsing errors may have copied secret text into logs (A-14). |
| `app/src/debug/java/dev/stunmesh/android/debug/ConfigImportReceiver.kt` | Debug-only exported unprotected broadcast receiver can replace/activate an imported tunnel. | A-11 applies to debug APKs, not the checked release APK. The merged manifest evidence records this split. |
| `ui/TunnelEditorScreen.kt`, `ui/AboutScreen.kt` | Hard-coded UI URLs are `https://dhtproxy2.jami.net` as an editable default OpenDHT proxy and `https://github.com/tjjh89017/stunmesh-android` as an About link. | The About link opens only after user action. The proxy becomes an actual network dependency when selected and the Go core starts. |
| Go AAR `mobile/`, `internal/mobilebind/`, `internal/plugin/builtin/` | STUN and WireGuard UDP, configured OpenDHT HTTP(S), optional Cloudflare API, and underlay DNS. | See the companion Go report and its network/process inventory. NaCl box authenticates discovery outside WireGuard (G-02); a decrypted endpoint can modify wireguard-go UAPI (A-01/G-01). |

No app-declared analytics, advertising, crash-reporting or general HTTP client SDK was found in the resolved runtime dependency graph. The Go AAR is the only network engine besides Android framework APIs and is separately compared against source and release artifacts. This inventory is bounded by the audited source, selected build variants and dependency metadata, not an Android device network capture.
